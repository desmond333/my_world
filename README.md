# Мой мир (Животное дня & Органайзер)

Уютное веб-приложение для ежедневного настроения и продуктивности: животное дня с мудрой мыслью, погода, праздники, трекер тренировок, финансы, задачи, языковые тренажёры (английский и грузинский), фильмы с «кайфометром», подписки и интерактивное веселье со Стэйтемом.

## Основные возможности

- **Главная страница дня**: животное дня, локальная погода и прогноз на 7 дней, повод дня, праздники, дни рождения, быстрая отметка тренировки.
- **Полезное (`/extra`)**:
  - Календарь тренировок с видами спорта и статистикой.
  - Учёт финансов (зарплата, разовые доходы в RUB, USD, GEL).
  - Продуктивность: повторяющиеся задачи, цели, мечты и статус.
  - Медиа: коллекция фильмов с кайфометром, чувствами после просмотра и поиском.
- **Разное (`/misc`)**:
  - Подписки: календарь регулярных оплат и напоминания.
  - Языковой тренажёр: карточки, 4-квиз, спринт и аудирование (английский и грузинский).
  - Веселье: лотерея со Стэйтемом, рандомайзер мемов, интерактивный гардероб и саундборд.
  - Лотерея: симулятор теории вероятностей.
- **Особенности**:
  - Быстрый начальный запуск (Lazy Loading & Code Splitting).
  - 8 сезонных тем (светлые и тёмные для каждого времени года).
  - Работает локально и оффлайн (`localStorage`).

## Стек

- React 19, TypeScript, Vite
- Zustand (локальные хранилища)
- @dnd-kit (перетаскивание задач и списков)
- Lucide React (иконки)
- Web Audio API (звуки и саундборд) & Web Speech API (озвучка языков)

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Проверка форматирования, линтинга и типов
npm run check

# Сборка production-бандла
npm run build
```
