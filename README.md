# TAU — Personal Dashboard & Productivity System

Высокопроизводительный офлайн-first персональный дашборд и органайзер на базе React 19 и Cloudflare Workers с облачной синхронизацией, многоуровневым локальным хранилищем, системой совместных задач и строгим контролем безопасности данных.

---

## Возможности

- **Животное дня (`/today`, `/animal/:id`, `/favorites`)**: курируемый каталог из ~100 пород и видов с ежедневной ротацией без повторов; изображения подобраны вручную, а описание вида точечно подтягивается из Википедии по выбранному животному; избранное.
- **Персональный дашборд дня (`/today`)**: сводка дня, локальный метеопрогноз на 7 дней (Open-Meteo API), праздники и памятные даты, быстрый трекинг активностей.
- **Управление задачами и целями (`/useful/productivity`)**: повторяющиеся задачи, долгосрочные цели, кольцевой прогресс и система продуктивности.
- **Взаимодействие между пользователями**: поиск контактов, взаимные заявки в друзья, делегирование задач партнёру/коллеге с отслеживанием статуса выполнения и настройками приватности приёма задач.
- **Заметки и документы (`/notes`)**: древовидная иерархическая структура страниц (Notion-style) с произвольным уровнем вложенности, навигационное боковое меню (Sidebar Tree) со свертыванием/развертыванием веток, каскадным удалением и безопасным перемещением страниц; блочный редактор структуры документов с независимыми блоками контента, загрузка и встраивание мультимедиа (изображения с предпросмотром, подписями и полноэкранным зумом, аудиозаписи со встроенным плеером, PDF-документы с интерактивным просмотром), поддержка drag-and-drop перетаскивания файлов с рабочего стола и вставки скриншотов из буфера обмена (`Ctrl+V`), быстрое контекстное меню команд через слэш (`/`), сортировка блоков Drag-and-Drop, переключение в текстовый режим Markdown, хлебные крошки и автосохранение в `IndexedDB`.
- **Тренировки и активность (`/training`)**: календарь занятий, аналитика серий (стриков), статистика по видам спорта.
- **Финансовый хаб (`/useful/finance`)**:
  - **Операции**: учёт поступлений и расходов по месяцам в рублях, долларах и лари, мультивалютный баланс, динамика за 12 месяцев и курсы валют.
  - **Банковские вклады**: мониторинг депозитов и накопительных счетов, учёт капитализации, автоматический расчёт пассивного дохода по дням, неделям, месяцам и годам, итоговая сумма к выплате, средняя взвешенная ставка.
  - **Кредиты и займы**: контроль ипотек, автокредитов и рассрочек, отслеживание остатка задолженности, ежемесячные платежи, дни списания, счётчик дней до ближайшей оплаты и быстрая фиксация платежей.
  - **Регулярные подписки**: управление цифровыми сервисами, периодичностью списаний и совокупной стоимостью обслуживания.
  - **Общий итог и прогноз**: сводка накоплений, доходов и расходов по всем четырём разделам, расчёт запаса накоплений и шестимесячный прогноз баланса.
  - **Советы**: премиум-раздел с уроками «плохая идея — хорошая идея» от котёнка-наставника; часть уроков открыта бесплатно, остальные показаны в размытом превью и открываются в магазине.
- **Учёт медиа (`/useful/media`)**: каталогизация книг, фильмов и игр со статусами и оценками.
- **Профиль риска (`/useful/finance`)**: выбор стратегии (осторожная/сбалансированная/смелая), влияющий на сценарий прогноза баланса.
- **Совместное времяпровождение (`/useful/together`)**: планирование окон доступности (еженедельных и на конкретную дату) с необязательной заметкой и просмотр доступности друзей.
- **Языковой модуль (`/useful/languages`)**: три вкладки — базовый английский для начинающих, продвинутый английский (идиомы, деловая лексика, чтение статей с переводом) и грузинский разговорник; карточки, квиз, аудирование, спринт и озвучка.
- **Фоновые звуки (`/useful/sounds`)**: процедурные звуковые сцены (дождь, камин, медитация) на Web Audio с анимацией воспроизведения.
- **Единый раздел «Полезное» (`/useful`)**: тренировки, финансы, продуктивность, дневник, напоминания, медиа, языки, звуки, развлечения и совместное время — с правым меню, сгруппированным по секциям.
- **Темы оформления**: базовые палитры Графит (по умолчанию), Nord и Solarized со светлым и тёмным вариантом; VIP-скины магазина — Весна, Лето, Осень, Зима, Киберпанк, Полночное золото, Фиалка и Аниме. Единый стиль скруглений с выбором «круглое / среднее / квадратное» (по умолчанию среднее).
- **Справка (`/help`)**: большая двуязычная инструкция по всем разделам приложения с поиском, боковой навигацией и аккордеоном разделов.
- **Приглашение друзей**: реферальная ссылка/код в аккаунте; за каждого зарегистрировавшегося друга — на выбор +1000 TAU-коинов или +2 месяца премиума. Премиум (в т.ч. пожизненный у администратора) открывает премиум-разделы; монеты покупают разделы навсегда.
- **Центр уведомлений**: колокольчик в шапке с индикатором непрочитанного, единый список заявок в друзья, назначенных задач, подарков и наград за рефералов, быстрые действия и переход к деталям.
- **Обратная связь с создателем**: форма «Написать создателю» (тема поддержка/идея/баг) прямо в приложении; сообщения сохраняются в D1 и читаются в админ-панели, позже подключается пересылка на почту.
- **Экономика фич и премиум**: единый реестр возможностей с явным статусом «бесплатно / премиум»; платные доступны с премиум-аккаунтом или после пожизненной покупки за TAU-коины. Цены: премиум на месяц $5, на год $10, пожизненно $15 (1 $ ≈ 100 коинов); реферал — за друга +1000 коинов или +2 месяца премиума.
- **Дозы анимаций**: базовый аккаунт видит половину каталога анимаций, премиум (или покупка наборa в магазине) — полную двойную дозу; учитывается системное `prefers-reduced-motion`.
- **Адаптивный интерфейс**: разделение плотности данных на упрощённый (минималистичный по умолчанию) и расширенный вид.

## Архитектура и надежность

- **Архитектура Feature-Sliced Design (FSD 2.1)**: модульная структура со строгим разграничением ответственности между слоями (`app/`, `pages/`, `widgets/`, `features/`, `entities/`, `shared/`), компонентная изоляция стилей и независимость бизнес-логики.
- **Offline-First & PWA**: полноценная автономная работа без интернет-соединения через Service Worker (Workbox) и стратегии кэширования `NetworkFirst` / `CacheFirst`.
- **Многоуровневое хранилище (Storage Tiering)**:
  - Легковесные настройки и UI-состояния: гибридный адаптер (`localStorage` + `IndexedDB`).
  - Объёмные текстовые массивы (заметки, документы): прямое асинхронное хранение в `IndexedDB` с неограниченной дисковой квотой.
- **API-клиент с валидацией**: типобезопасный Hono RPC (`hc<AppType>`) для синхронизации, REST-запросы и WebSockets; ответы проверяются схемами Valibot.
- **Edge ORM (Drizzle ORM & Drizzle Kit)**: типобезопасные запросы к Cloudflare D1 без оверхеда и автоматическая генерация декларативных миграций базы данных.
- **Схемная валидация данных (Valibot & @hono/valibot-validator)**: строгая типобезопасная проверка входных тел запросов на бэкенде и структуры снимков кэша на клиенте с минимальным размером бандла.
- **Real-Time коммуникация (WebSockets & Durable Objects)**: двусторонний канал реального времени для синхронизации состояния между пользователями.
- **Безопасность API (Cloudflare Edge Security)**:
  - Заголовки безопасности через `secureHeaders` (HSTS, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`).
  - Rate Limiting скользящего окна на маршрутах аутентификации (`/auth/login`, `/auth/register`) для защиты от brute-force атак.
  - JWT (HMAC-SHA256) с безопасными `httpOnly` куками для refresh-токенов.
  - Централизованное структурированное JSON-логирование запросов и ошибок в Cloudflare Workers.

## Технологический стек

### Frontend

- **Ядро**: React 19, TypeScript, Vite
- **Стейт-менеджмент**: Zustand + persist (`IndexedDB` / `hybridStorage`)
- **API Клиент**: Hono RPC (`hc<AppType>`), REST, WebSockets
- **Валидация данных**: Valibot
- **PWA**: `vite-plugin-pwa` (Workbox)
- **UI & Примитивы**: Headless UI (`@radix-ui/react-dialog`, `@radix-ui/react-slider`, `@radix-ui/react-switch`), чистый CSS на системных токенах оформления (без Tailwind и runtime CSS-in-JS)
- **Анимации**: `motion` — переходы страниц (fade), каскадное появление блоков, пружинная анимация чисел и параллакс-слои в `src/shared/ui/Motion/`
- **Drag-and-Drop**: `@dnd-kit/core`, `@dnd-kit/sortable`
- **Иконки**: `lucide-react`
- **Анализ сборки**: `rollup-plugin-visualizer` (интерактивный отчёт `dist/stats.html`)

### Backend (`worker/`)

- **Среда выполнения**: Cloudflare Workers (V8 Edge Isolates)
- **HTTP**: Hono v4
- **База данных & ORM**: Cloudflare D1 (распределённая SQLite на Edge), Drizzle ORM (`drizzle-orm/d1`), Drizzle Kit
- **Валидация на Edge**: `@hono/valibot-validator` + Valibot
- **Real-Time**: Cloudflare WebSockets, архитектурный план Durable Objects
- **Безопасность**: Hono `secureHeaders`, кастомный Rate Limiting middleware, Web Crypto API (PBKDF2, HMAC-SHA256)

### Тестирование и DevOps

- **Фронтенд-тестирование**: Vitest
- **Бэкенд-тестирование**: `@cloudflare/vitest-pool-workers` (тестирование внутри V8 Miniflare с изолированной in-memory базой D1)
- **Контроль качества**: ESLint, Prettier
- **Автоматизация Git-хуков**: Husky + lint-staged (проверка линтером, форматирование изменённых файлов и валидация TypeScript `tsc -b --noEmit` при коммите)

## Установка и запуск

### Frontend

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (http://localhost:5173)
npm run dev

# Проверка качества кода (Prettier, ESLint, TypeScript)
npm run check

# Запуск тестов
npm run test:run

# Сборка production-бандла с генерацией stats.html
npm run build
```

### Backend (Cloudflare Worker)

```bash
# Переход в директорию worker
cd worker

# Установка зависимостей
npm install

# Генерация миграций Drizzle ORM
npx drizzle-kit generate

# Применение локальных миграций базы данных D1
npm run migrate:local

# Запуск интеграционных тестов с in-memory D1
npm test

# Деплой в Cloudflare Workers
npm run deploy
```
